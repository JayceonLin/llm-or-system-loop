# 任務單 13：另一條研究路線：訓練 LLM 本身更會建模

- 角色：concept
- data-wiki：topics/training-and-data.md topics/evaluation.md overview.md
- data-points：K23
- 這張要講：
  - **資料合成**：自動產生更多「題目＋模型」的練習資料
  - **監督式微調**：用這些資料再訓練 LLM
  - **對齊**：讓模型的輸出更符合偏好
  - 綜述（整理整個領域的方法、資料集與未來方向的論文）以統一方式重測，微調過的 ORLM-LLaMA-3 8B 在 IndustryOR 得到 42.9%、在 ComplexLP 得到 59.5%（兩份都是評估用的考卷），在較難的資料集上勝過 Chain-of-Experts
  - 還沒解決：長的推理過程很難標註；針對最佳化建模的訓練技術研究還不夠
- 新術語（第一次出現，要用白話解釋）：資料合成、監督式微調、對齊、綜述

- 不要講：OR-Instruct、LLMOPT、KTO、MILP-Evolve 等例子名稱；用求解器回饋當強化學習獎勵的建議
