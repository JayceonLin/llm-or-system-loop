第 3 站：LLM 寫程式，真正的計算交給求解器

系統LLM 寫什麼
OptiMUS用 Gurobi 或 cvxpy 寫 Python 程式
Chain-of-ExpertsLP 格式檔（求解器可以直接讀的模型文字檔，自製術語表）與 Gurobi 程式
OptiGuideCoder 把問題、背景與範例組成提示，讓 LLM 寫程式
  • 為什麼分工：LLM 擅長讀懂文字，求解器擅長精確計算
  • LLM 會算錯，也會重複產生以前的解
  • 讓 LLM 直接找解的 OPRO，問題變大後就輸給專門的方法

成本：OptiMUS 成功的執行，不含求解器時間，每次都在 7 分鐘內完成；平均用掉 4117.1 ± 1509.7 個 token（LLM 讀寫文字時的計算單位，用得越多，通常花的時間與費用也越多，自製術語表）。
