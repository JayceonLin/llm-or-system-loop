# 任務單 12：另一條路：OPRO 讓 LLM 直接提出解，看分數再改進

- 角色：concept
- data-wiki：topics/llm-as-optimizer.md system/03-code-and-solver.md
- data-points：K18
- 這張要講：
  - **元提示**：提示裡放問題描述，與之前的解和分數
  - 流程：LLM 根據元提示產生新的解，每一步最多 8 個 → 計算新解的分數 → 把新解與分數加進元提示
  - **旅行推銷員問題**（拜訪每個城市一次、總路程最短）和最佳解的差距，越小越好：10 個城市 OPRO（gpt-4）0.0%、最遠插入法 3.2%；50 個城市 OPRO 11.0%、最遠插入法 9.8%；OPRO 從 20 個城市開始，就輸給專門的方法（最遠插入法）（最後這句放重點框）
  - 主要用途是最佳化提示詞；作者說它不是要贏過求解器，大問題也放不進提示
- 新術語（第一次出現，要用白話解釋）：元提示、旅行推銷員問題、最遠插入法（只說它是專門的方法，不要自己解釋演算法）
- 不要講：15、20 個城市那兩列的數字（0.2%、1.2%、1.4% 等；重點框的「從 20 個城市開始」要講）；最近鄰居法；GSM8K、Big-Bench Hard 的數字；不需要梯度；從 5 個隨機解開始
